# Проверка UX/UI через agent-browser

Дата: 2026-09-30. Локальный сервер: http://localhost:3000.
Инструмент: agent-browser 0.38.1 из npm-кэша, Chromium через
`/tmp/hirerank-chrome-verify.sh` с кэшированными системными библиотеками.
Авторизация: настроенный локальный владелец; сценарии UI выполнены в Dev mode.
Серверные записи не создавались, не изменялись и не удалялись.

## Результаты

| Сценарий | Результат |
| --- | --- |
| Анкета → HR Copilot → вакансия | Все три панели открываются; описание и требования доступны справа от Copilot |
| Новая панель за границей контейнера | Автоматически прокручивается в видимую область |
| Расширение уже открытой панели | Правая граница остаётся видимой после изменения ширины |
| Прокрутка страницы | Верх контейнера панелей остаётся на 16 px при scrollY=650 и 902 |
| Изменение ширины клавиатурой | ArrowLeft меняет ширину с 360 до 384 px |
| Изменение ширины мышью | Перетаскивание влево на 60 px увеличило ширину с 384 до 444 px |
| Независимый скролл Copilot | В окне 1440×650 scrollTop=173, содержимое 722 px, область 549 px; scrollY страницы не изменился |
| Мобильная разметка | При ширине 390 px ширина документа также 390 px; панели идут вертикально, ручки скрыты, содержимое прокручивается отдельно |
| Промежуточные размеры | При ширинах 768 и 1024 px ширина документа совпадает с viewport |
| Вакансии | Список остаётся на экране при открытых деталях; закрытие возвращает полный список |
| Карточки пользователей | Аватарки, имя, email, роль, статус и разрешённые кнопки отображаются |
| Форма пользователя | Открытие и отмена работают; у администратора нет superuser в списке ролей; сохранение не выполнялось |
| Меню ролей | Главная, вакансии, кандидаты, календарь, агент, Copilot, настройки, поддержка видны для всех шести демо-ролей |
| Профиль | Подпись корректна для HR, рекрутера, менеджера, кандидата, администратора и суперюзера |
| Настройки | Смена темы через UI работает; сохранение демо-настройки показывает статус |
| Поддержка | Раздел наполнен инструкциями; метки «Скоро» отсутствуют |
| Светлая / тёмная темы | Скриншоты осмотрены; кнопки, границы и текст различимы; инициалы аватарок белые в обеих темах |
| Ошибки браузера | agent-browser errors не вернул ошибок; Next.js error overlay отсутствует |

## Исправления по итогам браузерной проверки

- Начальная ширина панели уменьшена до 360 px.
- Добавлено автоматическое горизонтальное раскрытие новых и расширяемых панелей.
- На мобильном экране новая панель прокручивается в поле зрения.
- Скруглены верхние углы заголовка панели.
- Исправлен контраст инициалов аватарок в тёмной теме.
- В карточках пользователей действия выровнены в отдельном нижнем ряду.
- Для отсутствующих требований вакансии добавлен явный текст пустого состояния.

Скриншоты проверки сохранены в `/tmp/hirerank-ux-final-light.png`,
`/tmp/hirerank-ux-final-dark.png`, `/tmp/hirerank-ux-final-mobile.png`,
`/tmp/hirerank-ux-jobs-dark.png`, `/tmp/hirerank-ux-users-dark.png`.

Проверка покрывает интерфейс демо и чтение локальных данных. Реальные CRUD-записи,
LLM-интеграция и отправка обращений в поддержку этим прогоном не проверялись.

Статические проверки: TypeScript, ESLint изменённых компонентов, `git diff --check` и production-сборка Next.js проходят.
